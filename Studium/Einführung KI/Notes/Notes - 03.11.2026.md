# Konzepte
## Wissensbasierte Systeme
- Regelbasierte Systeme, semantisch vernetzte Systeme, oder auch Expertensystem Wissen abrufen.
- Schlussfolgerungen (anhand festgelegter Regeln).
## Maschinelles Lernen
- Regression, Clustering, Klassifikation.
- Synthetisieren von Informationen.

**Inferenz = Schlussfolgern:**
```
Anhand Eingabedaten erarbeitet das gewählte KI-Verfahren ein Ergebnis, die einer
Schlussfolgerung gleicht. Dies kann einstufig oder mehrstufig geschehen. Regeln sind
„harte Vorgaben“:
Hier gibt es drei unterschiedliche Arten des Schlussfolgerns:
Deduktion, Induktion und Abduktion.
```

**Ungewissheit (Uncertainty):**
```
Wir können nur mit einer begrenzten Gewissheit Ergebnisse berechnen, da nicht alle
möglichen Eingabe-Ausgabe-Paare vorliegen. Damit ist automatisch eine gewisse
Unsicherheit bei der Vorhersage verbunden. Harte Computation ist hier nicht möglich.
```
