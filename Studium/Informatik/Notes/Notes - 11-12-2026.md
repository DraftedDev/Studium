## Definition
### Automat (ohne Ausgabe)
- *Ein deterministischer Automat ohne Ausgabe ist ein Tripel $(Q, \Sigma, \delta)$.*
	- $Q = \{q_{0}, q_{1}, q_{2}\}$ - Eine Menge von Zuständen.
	- $\Sigma = \{\sigma_{0}, \sigma_{1}, \sigma_{2}\}$ - Eine Menge von Eingabezeichen.
	- $\delta: Q \times \Sigma \to Q$ - Eine Übergangsfunktion.

## Nachrichtenverarbeitung
### Nachrichten
- Eine Nachricht ist eine aus den Zeichen eines Alphabets gebildete Zeichenfolge.
- Ein Automat ($Q, \Sigma, \delta, Y, g, z_{s}, E$) besitzt ein Eingabealphabet.
- Wenn unsere Nachricht aus Zeichen von $\Sigma$ besteht, welche Nachrichten akzeptiert der Automat?
### Beispiel
- $\Sigma = \{0, 1\}$
- $Q = \{a, b\}; \quad q_{s} = a; \quad E = \{b\}$
- $\delta(a, 0) = a; \quad \delta(a, 1) = b$
- -> Jede Nachricht, die beliebig viele 0 hat und dann mit einer 1 endet.

## Fangzustand
- Ist der Automat im Endzustand, dann hat er eine Nachricht erfolgreich gelesen.
- Wie sollen Fehler signalisiert werden?
- *Alternative 1:* separater Zustand, analog Endzustand.
- *Alternative 2:* Zustand in dem der Automat gefangen bleibt.
=> *Ein Fangzustand $x$ ist ein Zustand aus $Q$, für den gilt: $\delta(x, \sigma) = x$, für alle $\sigma \in \Sigma$.*

## Akzeptierte Sprache
- Eine Sprache ist eine Teilmenge von $\Sigma^*$.
- Sei $A = (Q, \Sigma, \delta, q_{s}, F)$ ein Automat.
- Die akzeptierte Sprache des Automaten $A$ wird als $L(A)$ bezeichnet.
- $L(A) = \{m \in \Sigma^* | \delta_{|m|}(m) \in F\}$
## Bemerkungen
- Im Kontext von Sprachen wird von Worten gesprochen, nicht immer von Nachrichten.
- Entsprechend wird die Variable $w$ genutzt, statt $m$.
- $L(A)$ ist so zunächst nur für einen deterministischen, endlichen Automaten definiert.
	- Man kann die Definition für nichtdeterministische, endliche Automaten erweitern.
	- Auch für nichtendliche Automaten, sofern die Nachricht endlich ist.
- Wenn der Automat $A$ aus dem Kontext klar ist, dann statt $L(A)$ kurz $L$ geschrieben.
- Unterschiedliche Automaten können die gleiche Sprache akzeptieren.
## Anwendungen
- Automaten erkennen, ob ein Wort $w \in \Sigma^*$ zur Sprache $L$ des Automaten gehört.
- *Beispiele:*
	- Ein Automat kann die Schlüsselworte von Python (oder anderen Programmiersprachen) erkennen.
		- `def, while, if, etc.`
	- Automaten können auch erkennen, dass eine Zeichenfolge kein Schlüssel wort ist.
	- Erkennen, dass eine Mailadresse wohlgeformt ist.
	- Korrekt aufgebaute URL oder Telefonnummer.
	- Ist eine Zeichenfolge in einer anderen enthalten?
- Mit Hilfe eines Ausgabealphabets können Zeichenfolgen in andere übersetzt werden.
	- Telefonziffern in Tonhöhe.
	- Idee: Python in Byte-Code ("py" -> "pyc"); Byte-Code in Maschinencode.
